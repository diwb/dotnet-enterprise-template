# Roadmap

## v1.0.0

- Clean Architecture solution
- B2B commerce domain
- JWT authentication and role policies
- EF Core SQL Server persistence
- Docker Compose
- CI restore/build/test
- Documentation baseline
- Open source templates and security policy
- CodeQL and package vulnerability checks

## v2.0.0

- Add repository and specification abstractions where query complexity justifies them
- Add refresh-token rotation endpoint
- Add order search and payment endpoints
- Add Testcontainers-based SQL Server integration tests
- Add OpenTelemetry traces and metrics

## v3.0.0

- Publish installable project template package
- Add deployment blueprints for Azure Container Apps and Kubernetes
- Add multi-tenant reference module
- Add architecture decision automation and documentation site generation
- Publish NuGet/template package
